Preguntas frecuentes

Dudas comunes sobre Git y GitHub que surgen al trabajar en equipo en este proyecto.

Conceptos básicos

¿Qué es Git?

Git es un sistema de control de versiones. Guarda el historial de cambios de un proyecto para que puedas volver a versiones anteriores y trabajar con otras personas sin perder información.

¿Cuál es la diferencia entre Git y GitHub?

Git es la herramienta que se instala en tu computadora. GitHub es una plataforma en Internet donde se guardan los repositorios para compartirlos y colaborar con otros.

¿Qué es un commit?

Es una "foto" del proyecto en un momento dado, con un mensaje que explica qué cambió. Se crea con git commit -m "mensaje".

Trabajo con ramas

¿Qué es una rama (branch)?

Es una línea de trabajo independiente. Permite hacer cambios sin afectar la rama principal (main) hasta que estén listos.

¿Cómo creo mi propia rama?

Con git checkout -b nombre-de-mi-rama se crea la rama y te cambias a ella en un solo paso.

¿Cómo subo mi rama a GitHub?

La primera vez usa git push -u origin nombre-de-mi-rama. Después basta con git push.

Colaboración

¿Qué es un Pull Request?

Es una solicitud para unir los cambios de tu rama con main. El responsable del repositorio los revisa y decide si los acepta (merge).

¿Qué es un conflicto y cómo se evita?

Ocurre cuando dos personas modifican las mismas líneas de un archivo. Se evita trabajando en archivos distintos y actualizando tu rama seguido con git pull origin main.

¿Cómo actualizo mi proyecto con los cambios de otros?

Usa git pull origin main para traer los últimos cambios de la rama principal a tu copia local.
