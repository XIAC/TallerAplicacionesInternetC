Información del Taller

El Taller de Apps Internet es un espacio de aprendizaje donde los estudiantes desarrollan aplicaciones web modernas utilizando HTML, CSS y JavaScript. Aquí encontrarás toda la información relevante sobre el curso.

¿Qué es este taller?

Es un taller práctico orientado al desarrollo de aplicaciones web. Los estudiantes aprenden desde la estructura básica de una página HTML hasta la creación de aplicaciones dinámicas con JavaScript, aplicando buenas prácticas de diseño, accesibilidad y organización de archivos.

Objetivos

  • Comprender la estructura de un documento HTML5.
  • Aplicar estilos con CSS para lograr diseños atractivos y responsivos.
  • Programar interactividad con JavaScript (DOM, eventos, almacenamiento).
  • Organizar proyectos web con carpetas y buenas prácticas.
  • Desarrollar una aplicación web funcional como proyecto final.

Temas del taller

🌐 HTML5

Estructura semántica, formularios, enlaces y multimedia.

🎨 CSS3

Selectores, Flexbox, Grid, diseño responsive y animaciones.

⚡ JavaScript

Variables, funciones, DOM, eventos y localStorage.

🗂️ Organización

Estructura de carpetas, rutas relativas y control de versiones.

Modalidad y duración
