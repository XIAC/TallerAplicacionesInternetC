Sobre el sistema

Este sistema web permite gestionar la información básica de los estudiantes: registrarlos, consultarlos en una lista y mantener sus datos actualizados.

Fue desarrollado como práctica de la materia Taller de Aplicaciones en Internet, usando únicamente tecnologías del lado del cliente.

Consultar

Revisa la lista de estudiantes registrados desde la página Estudiantes.

Registrar

Agrega un nuevo estudiante con su nombre, correo, carrera y semestre.

Administrar

Edita o elimina los datos de un estudiante cuando cambien.

Tecnologías utilizadas

  • HTML5 para la estructura de las páginas.
  • CSS3 para el diseño, con variables de color para el modo oscuro y claro.
  • JavaScript para la lógica del formulario y la lista de estudiantes.
  • localStorage para guardar los datos en el navegador, sin servidor.

Estructura del proyecto

  • index.html: página de inicio.
  • paginas/: estudiantes, registrar e información.
  • css/estilos.css: estilos generales.
  • js/: app.js y estudiantes.js.

Modo oscuro y claro

Usa el botón de la barra de navegación para cambiar el tema. Tu elección se guarda y se mantiene al cambiar de página.
